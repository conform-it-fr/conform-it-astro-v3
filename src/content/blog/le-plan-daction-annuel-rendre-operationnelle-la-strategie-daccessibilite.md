## Introduction

Le plan d’action annuel est le document qui traduit concrètement la démarche d’accessibilité numérique dans le quotidien des organisations. Là où le schéma pluriannuel fixe une stratégie globale sur plusieurs années, le plan annuel définit, de manière précise, les actions à mener sur une période d’un an.

Il s’agit d’un outil opérationnel essentiel pour passer de l’intention à l’action, suivre les progrès et structurer les travaux autour d’objectifs réalistes et mesurables.

## Un document au cœur de la mise en œuvre

Le plan d’action annuel sert à organiser la mise en accessibilité de manière progressive et structurée. Il permet de :

- Définir les priorités de l’année
- Planifier les audits et les corrections
- Répartir les responsabilités
- Suivre l’avancement des travaux
- Mesurer les résultats obtenus

C’est un document de pilotage concret, utilisé par les équipes projet, techniques et éditoriales.

## Le lien avec le schéma pluriannuel

Le plan annuel s’inscrit directement dans la continuité du schéma pluriannuel. Il en constitue la déclinaison opérationnelle.

Par exemple :

- Le schéma pluriannuel fixe comme objectif la mise en conformité des sites principaux
- Le plan annuel précise quels sites seront audités cette année, quelles corrections seront engagées et quels moyens seront mobilisés

Il permet de structurer les actions étape par étape.

## Les éléments clés d’un plan d’action annuel

Un plan d’action annuel efficace repose sur plusieurs composantes essentielles.

### 1) Les actions à mener

Le document liste les travaux prévus pour l’année, par exemple :

- Réalisation d’audits RGAA
- Correction des non-conformités prioritaires
- Refonte de certains services numériques
- Amélioration des contenus existants
- Mise en accessibilité de documents PDF

Ces actions doivent être concrètes et identifiables.

### 2) Les priorités

Toutes les actions ne peuvent pas être menées en même temps. Le plan annuel permet de hiérarchiser :

- Les services les plus utilisés
- Les contenus critiques pour les usagers
- Les fonctionnalités bloquantes

Cette priorisation rend la démarche plus efficace.

### 3) Les responsables

Chaque action doit être associée à un acteur clairement identifié :

- Équipe technique
- Équipe éditoriale
- Prestataire externe
- Référent accessibilité

Cela facilite le suivi et la coordination.

### 4) Le calendrier

Le plan annuel précise généralement :

- Les périodes d’audit
- Les phases de correction
- Les temps de formation
- Les étapes de validation

Un calendrier clair permet d’éviter que les actions soient repoussées.

### 5) Les moyens mobilisés

Le document peut mentionner les ressources prévues :

- Temps de travail dédié
- Budget pour des audits ou des outils
- Accompagnement externe
- Actions de sensibilisation

Cela montre l’engagement réel de l’organisation.

## Des actions variées selon le niveau de maturité

Le contenu du plan annuel dépend souvent de la situation de départ.

Dans une organisation qui débute, les premières actions peuvent être :

- Réaliser un état des lieux
- Sensibiliser les équipes
- Former les acteurs clés
- Lancer les premiers audits

Dans une organisation plus avancée :

- Corriger des non-conformités ciblées
- Intégrer l’accessibilité dans les projets en cours
- Mettre en place des contrôles réguliers
- Améliorer les pratiques éditoriales

Le plan évolue au fil des années.

## Le suivi des actions

Le plan annuel n’est pas seulement un document de prévision. Il sert aussi à suivre les résultats.

On peut y retrouver :

- Des indicateurs de progression
- Le statut des actions (prévue, en cours, réalisée)
- Les difficultés rencontrées
- Les ajustements nécessaires

Ce suivi permet d’ancrer la démarche dans la durée.

## Un outil de coordination interne

Le plan d’action annuel facilite le travail collectif. Il permet :

- D’aligner les équipes sur des objectifs communs
- De rendre visibles les efforts engagés
- De structurer la collaboration entre métiers
- D’éviter les initiatives isolées

Il donne un cadre partagé à la démarche d’accessibilité.

## Une publication recommandée

Dans le secteur public, le plan d’action annuel est généralement rendu public, aux côtés :

- De la déclaration d’accessibilité
- Du schéma pluriannuel

Cette publication contribue à la transparence et permet aux usagers de suivre les engagements pris.

## Erreurs fréquentes à éviter

Un plan d’action peut perdre en efficacité lorsqu’il :

- Reste trop général
- Ne fixe pas d’échéances claires
- N’identifie pas les responsables
- N’est pas suivi dans le temps
- N’est pas mis à jour

Dans ces cas, il devient un simple document administratif.

## Bonnes pratiques pour un plan utile

Pour être réellement opérationnel, un plan annuel doit :

- Définir des actions concrètes et réalistes
- Être cohérent avec les moyens disponibles
- Être suivi régulièrement
- Être partagé avec les équipes concernées
- Être ajusté si nécessaire

Il doit rester un outil vivant.

## Un levier pour progresser chaque année

Le plan d’action annuel permet de construire une amélioration continue. Même si tout ne peut pas être corrigé immédiatement, il structure une progression régulière :

- Identifier
- Prioriser
- Corriger
- Évaluer
- Ajuster

Chaque année contribue à renforcer le niveau global d’accessibilité.

## Conclusion

Le plan d’action annuel est le document qui rend la démarche d’accessibilité concrète et opérationnelle. En définissant des actions précises, des priorités, des responsables et un calendrier, il permet de transformer les objectifs stratégiques en réalisations tangibles.

Associé au schéma pluriannuel et à la déclaration d’accessibilité, il constitue un outil essentiel pour piloter une démarche structurée, progressive et durable en faveur d’un numérique accessible à tous.
