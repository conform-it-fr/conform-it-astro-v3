**80 % des sites développés avec un CMS de type Wordpress** **concernent des sites dits "Vitrine" donc statiques.**

Comme beaucoup, par simplicité peut-être, je me suis d'abord orienté vers un site Wordpress. Simple à mettre en place quand tu as un bon hébergeur, prise en main un peu compliquée compte tenu de la myriade de plugins et de thèmes proposés. Enfin, après quelques heures de travail, voila mon site en ligne.

Dans le cadre de la mise en conformité des sites, il est également important de mesurer l'impact environnemental. Donc je le teste sur EcoIndex et voici le résultat. **Catastrophique !**

![Description des Résultat EcoIndex - Ancien site](/images/articles/eco-conception-et-site-statique-comment-faire-passer-l-ecoindex-de-d-a-a-pour-un-meme-site-resultat-ecoindex-d.webp)

Alors, après quelques recherches, je décide de le migrer vers un site statique. En effet, compte tenu des informations présentes sur le site, elles ne changent pas souvent; inutile d'avoir une machine de guerre, certes pratique et conviviale, pour afficher quelques pages et articles. Encore un peu d'effort (plus technique pour le paramétrage) et nouveau site, équivalent dans son contenu au précédent.

Avec des **indicateurs comparatifs assez éloquents (au 28/10/25)** :

|  |  |  |  |
| --- | --- | --- | --- |
| pour 1000 visites/mois | AVANT | APRES | Evolution |
| Score EcoIndex (GreenIT) | 43 | 81 | + 88 % |
| Consommation d'eau | 32 l | 21 l | - 34 % |
| Emission de gaz à effet de serre | 2,14 kgCO2e | 1,4 kgCO2e | - 34 % |

|  |  |  |  |
| --- | --- | --- | --- |
| Poids de la page | 1,704 Mo | 0,674 Mo | - 60 % |
| Complexité | 768 éléments | 235 éléments | - 70 % |
| Requêtes | 78 | 23 | - 70 % |

Pour compléter, le site est sécurisé (pas de login), pas besoin de base de données sur un serveur, pas besoin de maintenance, pas de mise à jour pour chaque plugin utilisé.

De plus, en matière d'accessibilité, on obtient un score respectif :

|  |  |  |  |
| --- | --- | --- | --- |
| Wave (AIM score) | 7/10 | 9,7/10 | + 27 pts |
