## Introduction

Le schéma pluriannuel d’accessibilité est un document stratégique qui structure la mise en accessibilité des services numériques sur plusieurs années. Il constitue un pilier central de la démarche réglementaire, en particulier pour les organismes publics et assimilés.

Contrairement à la déclaration d’accessibilité, qui décrit un état à un instant donné, le schéma pluriannuel fixe une trajectoire. Il permet d’organiser, planifier et suivre les actions nécessaires pour améliorer progressivement l’accessibilité des sites web, applications et outils numériques.

## Un document de pilotage stratégique

Le schéma pluriannuel n’est pas un document technique. Il s’agit d’un outil de gouvernance qui répond à plusieurs objectifs :

- Structurer la démarche d’accessibilité dans le temps
- Donner une vision globale des engagements pris
- Planifier les actions sur plusieurs années
- Impliquer les différentes équipes concernées
- Suivre les progrès réalisés

Il permet de passer d’une logique ponctuelle (audit, correction) à une véritable stratégie d’amélioration continue.

## Une obligation réglementaire pour le secteur public

En France, les organismes publics soumis aux obligations d’accessibilité numérique doivent publier un schéma pluriannuel. Celui-ci s’inscrit dans un dispositif complet comprenant :

- La déclaration d’accessibilité
- Le schéma pluriannuel (stratégie sur plusieurs années)
- Le plan d’action annuel (actions concrètes à court terme)

Le schéma pluriannuel sert de cadre général à l’ensemble de ces éléments.

## Une vision sur plusieurs années

Comme son nom l’indique, le schéma pluriannuel couvre une période longue, généralement de trois ans. Il définit les grandes orientations et les priorités de l’organisation en matière d’accessibilité.

Il ne détaille pas toutes les actions techniques, mais précise :

- Les objectifs à atteindre
- Les services concernés
- Les axes d’amélioration prioritaires
- Les moyens mobilisés

Il pose les bases d’une transformation progressive.

## Les éléments clés d’un schéma pluriannuel

Même si sa forme peut varier selon les organisations, on retrouve généralement plusieurs composantes essentielles.

### 1) Le contexte et les enjeux

Le document présente le cadre dans lequel s’inscrit la démarche :

- Nature des services numériques concernés
- Publics visés
- Enjeux d’accessibilité spécifiques
- Niveau de maturité de l’organisation

Cette introduction permet de comprendre la situation de départ.

### 2) Les objectifs stratégiques

Le schéma doit définir une orientation claire. Par exemple :

- Mettre en conformité les sites principaux
- Intégrer l’accessibilité dans les nouveaux projets
- Former les équipes internes
- Améliorer la prise en compte des utilisateurs en situation de handicap

Ces objectifs donnent une direction globale.

### 3) Le périmètre des actions

Le document doit préciser quels services sont concernés :

- Sites internet
- Intranets
- Applications métiers
- Applications mobiles

Cela permet d’identifier l’ampleur du chantier.

### 4) L’organisation interne

Un schéma pluriannuel efficace décrit la manière dont la démarche est pilotée :

- Désignation d’un référent accessibilité
- Rôle des équipes techniques et éditoriales
- Implication de la direction
- Coordination entre les services

L’accessibilité devient alors un sujet transversal.

### 5) Les actions structurantes

Le document peut mentionner des actions majeures, par exemple :

- Réalisation d’audits réguliers
- Intégration de l’accessibilité dans les marchés publics
- Mise en place de formations
- Création de référentiels internes
- Suivi des indicateurs de conformité

Ces actions visent à ancrer l’accessibilité dans le fonctionnement quotidien.

## Le lien avec le plan d’action annuel

Le schéma pluriannuel fixe la stratégie. Le plan d’action annuel, lui, détaille les actions concrètes à réaliser chaque année.

Par exemple :

- Année 1 : audit des principaux sites et premières corrections
- Année 2 : refonte de certains services numériques
- Année 3 : généralisation des bonnes pratiques

Le plan d’action rend la stratégie opérationnelle.

## Un outil pour structurer la transformation

Mettre en accessibilité un écosystème numérique ne se fait pas en une seule fois. Le schéma pluriannuel permet de :

- Prioriser les efforts
- Répartir les ressources
- Planifier les travaux dans le temps
- Éviter les démarches isolées ou ponctuelles

Il transforme une obligation réglementaire en projet structuré.

## Erreurs fréquentes dans la mise en place

Certaines organisations rencontrent des difficultés lorsque le schéma pluriannuel :

- Reste trop général et peu concret
- N’est pas porté par la direction
- N’est pas mis à jour
- N’est pas articulé avec les actions réelles
- Est peu diffusé en interne

Dans ces cas, il perd son rôle de pilotage.

## Bonnes pratiques pour un schéma efficace

Pour être utile, le schéma pluriannuel doit :

- Être réaliste et progressif
- Être partagé avec les équipes
- S’appuyer sur des constats concrets (audits, retours utilisateurs)
- Être suivi dans la durée
- Être mis à jour si nécessaire

Il doit vivre avec l’organisation.

## Un levier de culture accessibilité

Au-delà de la conformité, le schéma pluriannuel contribue à installer une culture de l’accessibilité :

- Sensibilisation des équipes
- Intégration dans les processus de conception
- Prise en compte dès le démarrage des projets
- Amélioration continue des pratiques

Il permet de passer d’une logique corrective à une logique préventive.

## Conclusion

Le schéma pluriannuel d’accessibilité est un document stratégique qui organise la mise en conformité dans le temps. Il définit les objectifs, structure les actions et donne une vision globale des engagements pris par une organisation.

Complété par le plan d’action annuel et la déclaration d’accessibilité, il constitue un cadre solide pour piloter une démarche durable, progressive et cohérente en faveur d’un numérique accessible à tous.
